# Privacy

No analytics, advertising, remote embeds, or tracking pixels are configured.
Search runs locally in your browser. Fonts use the browser's installed fonts.
The favicon, styles, scripts, and diagrams are served with the site.

The optional **GitHub repository statistics** category is unchecked initially.
Until you enable it and accept, the site should not request the GitHub API.
Reject leaves it disabled. Accept saves the selected settings; it does not
implicitly select an unchecked category. Use **Change cookie settings** in the
footer at any time to reopen the native consent dialog.

Your consent choice is stored in browser local storage, scoped to the project
path. Theme and search preferences may also use local storage. Clearing browser
site data resets these preferences. GitHub Pages receives requests needed to
serve this site; following external links contacts the destination you choose.
GitHub hosting policies and server-side logs remain outside this site's control.

This describes the implemented controls, not a claim of GDPR compliance.
