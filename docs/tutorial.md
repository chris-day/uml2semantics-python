# uml2semantics Tutorial

This tutorial walks through:

1. Writing TSV files
2. Running the converter
3. Inspecting the resulting OWL
4. Understanding choice, facets, enumerations and annotations

- Use `examples/*.tsv` as the input model.
- Run `uml2semantics` as shown in the README.
- Inspect `examples/example-ontology.ttl` and `examples/example-ontology.manchester.owl` in Protégé or your favourite tools.
